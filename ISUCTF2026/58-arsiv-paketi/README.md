# 58. Arşiv Paketi

**Kategori:** Web Archive / Versiyon Karşılaştırma
**Konu:** Birden fazla HTML versiyonu arasından güncel/canlı olan tespit edilir; güncel sürüm farklı verileri taşır.

## Çözüm

Üç HTML dosyası karşılaştırıldı. Doğru/güncel kopya `archive_2026.html` dosyasıydı çünkü sayfada `LIVE PAGE` ve `CURRENT` ibareleri vardı.

2026 sayfasında Venue ve Session bilgisi `C4` olarak güncellenmişti:

```
Venue:        Block C — Hall C4
Session Code: C4
```

Version History tablosunda bu güncel kaydın birleşik referansı verilmişti:

```
ARCH-2026-C4
```

## Flag

```
ISUCTF{ARCH-2026-C4}
```
